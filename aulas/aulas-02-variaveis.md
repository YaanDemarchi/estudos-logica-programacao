Aula 02 — Variáveis
1. O que são variáveis?
Imagine que você tem algumas caixas e coloca informações dentro delas.

Uma caixa guarda seu nome, outra guarda sua idade e outra guarda sua altura.

Na programação, essas caixas são chamadas de variáveis.








algodaily.com


Uma variável é um espaço utilizado para armazenar uma informação que podemos utilizar durante a execução de um programa.
2. Exemplos de variáveis
Imagine que queremos armazenar os seguintes dados:
Variável	Valor
nome	João
idade	25
altura	1.75
cidade	São Paulo

Observe que cada variável tem um nome e guarda um valor.
3. Conhecendo os tipos de dados
Existem diferentes tipos de informações que podemos armazenar.

Texto (String)

Exemplo: "Maria"




Número inteiro (Integer)

Exemplo: 25




Número decimal (Float)

Exemplo: 1.75




Booleano (Boolean)

Exemplo: verdadeiro ou falso (True / False)



4. Como criar uma variável?
Vamos usar um exemplo em pseudocódigo:
nome = "João"
idade = 25
altura = 1.75


Isso significa:
- Criamos uma variável chamada nome e guardamos "João".
- Criamos uma variável chamada idade e guardamos 25.
- Criamos uma variável chamada altura e guardamos 1.75.
Uma observação: o sinal = significa atribuir um valor à variável.
